# LifePlay: Open World Life MMO

ブラウザで開くだけで遊べる「1人向け自由MMORPG風」ライフゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. WASD または 矢印キーで移動
3. E で近くのNPCや行動を実行
4. 画面下のボタンでも農業、釣り、狩猟、仕事、会話、裁判、冒険、休憩が可能
5. S キーで保存

## 実装内容

- 自由移動のオープンワールド風マップ
- 町・農場・森・海岸・遺跡のエリア分け
- NPCたちの存在と会話システム
- 農業、釣り、狩猟、仕事、裁判、冒険、休憩
- お金・HP・元気・満腹・名声・スキル・関係性
- ローカルストレージによるセーブ
- 日付と季節の進行
- 結婚や恋愛要素を含む生活シミュレーション

## 目標

自由度を重視し、単なるミニゲームではなく「一人の人生を自由に生きる」体験を目指しています。

このゲームはローカル開発向けのシンプルなHTML/CSS/JSで構成されています。
ビルド不要です。ファイルをそのままブラウザで開けば遊べます。
