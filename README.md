# LifePlay

ブラウザで遊べる 3D オープンワールド生活 RPG です。町で働き、畑を耕し、海で釣り、森や遺跡でスライムと戦いながら、住人と仲良くなって結婚することもできます。

- 公開URL(GitHub Pages 設定後): **https://yauuui.github.io/lifeplay-mmorpg/**
- ビルド不要。静的ファイルだけで動きます(Three.js は `vendor/` に同梱しているので CDN が落ちても動きます)。

## 遊び方

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | `W A S D` / 矢印キー(`Shift` でダッシュ) | 左下のスティック |
| 視点 | マウスドラッグ / ホイールでズーム | 画面右側をドラッグ |
| 話す・調べる・採集・釣り | `E` / `Space` | 「調べる」ボタン / 画面中央の表示をタップ |
| 攻撃 | `F` | 「攻撃」ボタン |
| 食べる | `1` | 「食べる」ボタン |
| メニュー / 地図 / セーブ | `I`(`Tab`) / `M` / `K` | 各ボタン |
| 閉じる | `Esc` | ✕ ボタン |

### 暮らしの流れ

1. **タイトル → キャラクター作成**: 名前・髪型・髪/肌/服の色・職業を選ぶ(3D プレビュー付き)。
2. **リーフタウン(町)**: 自宅・宿屋・雑貨屋・役所・鍛冶屋に入れる。役所では仕事(給料)と毎日更新の依頼掲示板。
3. **ひだまり農場**: 雑貨屋で種を買い、畑にまいて毎日水やり → 数日で収穫。自宅でパンやシチューを料理。
4. **しおかぜ海岸**: 岸や桟橋で釣り。合図(!)が出たら `E`。桟橋の先端は大物ポイント。
5. **ささやきの森 / 古代遺跡**: 木・岩・鉱石・薬草・花を採集。スライムを倒すとゼリーとお金。遺跡では水晶が出ることも。
6. **住人との交流**: 毎日話す・好きなものを贈ると好感度アップ。恋愛可能な住人は ♥4 以上で「誓いのペンダント」を渡すと結婚。
7. **時間と季節**: 現実1秒 = ゲーム内2分。昼夜で空と街灯が変化し、7日ごとに季節(春夏秋冬)が変わる。深夜2時を過ぎると倒れるので自宅か宿で眠ろう(眠ると自動セーブ)。

セーブデータはブラウザの localStorage に保存されます。動作が重い端末では「メニュー → システム → 画質」で影をオフにできます。

## ファイル構成

```
index.html          画面(タイトル / キャラ作成 / ゲーム HUD / 各パネル)
style.css           UI デザイン(PC・スマホ対応)
vendor/three.min.js Three.js r149(同梱・MIT License)
js/data.js          ゲームデータ(エリア・建物・アイテム・職業・NPC・依頼・季節)
js/characters.js    キャラクター / スライムの 3D モデルとアニメーション
js/world.js         ワールド生成(地形テクスチャ・街・森・農場・遺跡・海・山)、衝突判定、ミニマップ用地図
js/game.js          ゲーム本体(移動・カメラ・昼夜・NPC スケジュール・採集・農業・釣り・戦闘・経済・保存)
js/ui.js            HUD・ミニマップ・メニュー・会話・ショップ・トースト・タッチ操作
js/main.js          画面遷移(タイトル → キャラ作成 → ゲーム)と起動チェック
```

スクリプトは通常の `<script>` で読み込んでいるので、`index.html` をダブルクリックして直接開いても動きます。

## ローカルで動かす

```bash
# どちらか
open index.html                # そのまま開く
python3 -m http.server 8000    # → http://localhost:8000/
```

## GitHub Pages で公開する手順

1. この変更を `main` ブランチにマージする。
2. GitHub のリポジトリ画面で **Settings → Pages** を開く。
3. **Build and deployment → Source** を「**Deploy from a branch**」にする。
4. **Branch** を `main`、フォルダを `/ (root)` にして **Save**。
5. 1〜2 分待つと Pages 画面上部に URL が表示されます: `https://yauuui.github.io/lifeplay-mmorpg/`
   - リポジトリが Private の場合、無料プランでは Pages を使えません(Public にするか有料プランが必要)。
   - 反映状況は **Actions** タブの「pages build and deployment」で確認できます。
